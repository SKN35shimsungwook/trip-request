# 🧳 여행 신청서

전에 만든 [데이트 신청서](https://github.com/SKN35shimsungwook/date-request)를 1박 2일 여행 버전으로 바꾼 Streamlit 앱입니다.
처음에는 코스마다 시간표와 숙소 동선까지 짜 봤는데, 막상 같이 갈 사람한테 보여 줄 때는 그런 빡빡한 계획보다 "여기 가면 이런 게 좋아"가 더 중요하다고 느꼈습니다.
그래서 시간과 동선은 제가 알고 있으면 되고, 앱에서는 코스마다 매력만 크게 보여 주고 고르게 했습니다.

## 흐름

1. **신청**: "나랑 1박 2일 여행 갈래?" `좋아 💖` / `거절 🙅`
   - 데이트 신청서에서 쓰던 도망가는 거절 버튼을 그대로 가져왔습니다
2. **코스 고르기**: 첫날 코스 세 개 중 하나를 고릅니다. 카드에는 한 줄 매력만 보여 줍니다
   - 🏰 A. 여주 루덴시아: 동화 속 유럽 마을
   - 🏯 B. 용인 한국민속촌: 조선 시대로 시간여행
   - 🏺 C. 이천 도자기 체험: 둘이 만드는 기념품
   - 둘째 날은 세 코스 모두 곤지암 화담숲으로 이어집니다
3. **한 번 더**: 고르지 않은 두 코스의 숨은 매력을 하나씩 더 보여 줍니다. 마음이 바뀌면 그 자리에서 바꿀 수 있습니다
4. **완성**: 풍선 🎈과 여행 확인서가 나오고 `.txt`로 저장할 수 있습니다

## 실행

```bash
git clone https://github.com/SKN35shimsungwook/trip-request.git
cd trip-request
pip install -r requirements.txt
streamlit run app.py
```

> 핑크 테마(`.streamlit/config.toml`)는 저장소 루트에서 실행해야 적용됩니다. Streamlit Community Cloud에서는 자동으로 적용됩니다.

## 구조

| 파일 | 설명 |
| --- | --- |
| `app.py` | 앱 전체. 코스 문구는 파일 맨 위 `COURSES`에서 고칩니다 (`hook` 카드 문구, `extra` 한 번 더 문구, `night` 확인서 첫날 밤) |
| `.streamlit/config.toml` | 핑크 테마 색상 |

- 페이지 전환: `st.session_state.step` (0~3)
- 도망가는 버튼: `st.components.v2.component` (HTML/CSS/JS). `좋아`를 누르면 `setTriggerValue`로 파이썬에 알립니다

## 배운 점

- 계획을 세우는 사람에게 필요한 정보와 고르는 사람에게 필요한 정보는 다르다는 걸 느꼈습니다. 동선 계산은 뒤에서 하고, 화면에는 고를 이유만 남기니 훨씬 가벼워졌습니다.
- 바로 확정하지 않고 다른 코스의 매력을 한 번 더 보여 주는 단계를 넣으니, 고르는 과정 자체가 대화 거리가 됐습니다.
